# 在在 · 安卓日常助手 MVP

邀请制内测，不接真实支付。文字、语音都调用配置的 CPA，没有用预置台词代替模型回复。

## 当前实现

- 底部顺序：记账、待办、中央新建、健康、我的；打开或刷新默认进入记账。助手入口位于右上角，设置收在“我的”页面内。
- 界面采用钉钉风格的蓝白配色，保留白色明细列表、按品类着色的图标和在在自身标识。
- 记账独立分为明细和统计，各工具页面只显示对应的待确认记录；通话控制条不阻止切换页面。
- 注册、登录、独立账号数据、密码哈希、会话过期及内测邀请码。
- “我的”提供设置、使用帮助、意见反馈和版本号；不再显示独立账户安全中心。修改密码移至“账号设置 → 密码设置”，须验证当前密码并重复确认新密码，保留当前会话、撤销其他会话并结束语音连接；暂不支持短信或邮箱找回。
- 点击“我的”头像进入全屏账号设置：展示真实只读 ID，修改昵称、性别和头像，复用密码修改入口，并在确认后退出登录。头像先在本机裁剪成 256×256 JPG 缩略图，点保存后仅写入本应用数据库；助手查询资料不包含头像。手机号、微信和邮箱绑定显示“暂未开通”，不模拟验证或保存绑定信息；尚无完整个人信息导出。
- 申请注销须输入当前密码、勾选说明并二次确认；提交后等待管理员审核，期间可继续使用或撤回申请，不立即删除数据。
- 意见反馈保存在本应用 SQLite 的 `feedback` 表中，不自动附带账目、聊天或设备信息；可查看本人最近 20 条提交，重试防重复，每 24 小时最多 10 条。版本号读取 `package.json`，无自动更新或付费入口。
- 温柔、直球、嘴损三种性格，共享聊天、长期偏好和真实记录。
- 实时语音输入、语音输出、中文字幕、自动插话、播放停止与上游上下文截断。
- 通话使用底部控制条，不打开全屏通话界面；可以继续切换页面、记账和处理待办。
- 不按通话创建新的聊天框。所有通话转录与文字消息保留在同一条历史中，刷新后仍在。
- 通话中输入文字会送入当前实时会话，不另起一次文字模型对话。
- 记账、待办提醒、体重记录；AI 只创建草稿，用户核对确认后才正式保存。
- 待办完成、修改提醒时间、记录删除；体重趋势和月度收支。
- 手动填写后一次保存；AI 支持一句话创建多笔草稿及更正原草稿，仍需用户确认。
- 账目批量核对、修改、回收站恢复；新表单带版本核对，避免旧内容覆盖新修改。
- 按月、具体日期、收支及分类筛选；已确认账目汇总与可展开的分类统计。
- 导出当前筛选结果为 CSV；浏览器下载，安卓使用系统文件保存窗口，不申请整个存储空间权限。
- 助手页支持拍照/相册识别人民币购物小票。商品按品类列出，可修改名称、数量、小计与整单优惠；合计一致且用户核对后才入账。
- 一张小票是一笔支出，商品明细随账目保存，点开可查看或修改。整笔分类用于账本统计，商品品类用于小票内部展示，不重复计账。
- 图片仅用于此次识别，不保存原图；小票日期、金额或数量看不清时要求用户核对。原图压缩后重复上传会提示已入账，不同照片/不同裁剪仍需用户自行核对。
- 查看/删除记忆、清空聊天与记忆、暂停关心 24 小时、夜间免打扰。
- 后端结合待办、聊天、记忆和记账情况判断是否主动关心，模型可以选择不打扰。
- 主动关心每天最多 3 次、至少间隔 3 小时，21:00–08:00 静默；未回复不连续追问，同一待办不重复询问。
- 晚间可询问漏记收支或临时新增事项；没有记录不等于没完成或发生过消费，仍需用户确认草稿。
- 安卓本地通知；用量记录与禁用状态的支付接口。
- 未成年人仅朋友模式；成年人主动选择亲密模式，不改变工具权限。

## 本机体验

当前 Wi-Fi 内测服务地址：`http://172.17.0.174:8787`（2026-09-16）。
当前进程只绑定这个局域网地址，不监听 `127.0.0.1`；没有配置公网映射或修改防火墙。
电脑换网或地址变化后需重新确认地址。电脑须保持开机并运行服务。

账号密码和邀请码不随源码发布，请在自己的部署中创建测试账号。
运行连接真实服务的 smoke 测试时，通过 `TEST_USERNAME` 和 `TEST_PASSWORD` 环境变量提供测试账号，通过 `INVITE_CODE` 提供邀请码。

CPA 密钥可加密保存在当前 Windows 用户的 `%LOCALAPPDATA%\Zaizai\backend-credential.xml`，使用 Windows DPAPI 保护，不写入前端、APK 或源码。
进程停止后，运行以下命令会自动读取已保存配置；没有保存配置时才提示输入密钥：

```powershell
.\scripts\start.ps1
```

加密文件仅适用于同一台电脑的同一 Windows 用户，不应提交或分享。显式提供的环境变量优先；若环境中的 API 地址与保存的地址不同，脚本会拒绝自动使用保存的密钥。HTTPS 连接失败时不会自动切换 HTTP。

有环境变量时脚本不会重复询问。默认仅监听本机，不修改防火墙、不暴露公网。
继续使用当前 Wi-Fi 内测地址时，改用：

```powershell
.\scripts\start.ps1 -BindAddress '172.17.0.174'
```

未设置 `INVITE_CODE` 时，服务会随机生成邀请码并打印在终端。
不要直接在公开服务器上使用本内测配置。

安装包位于 `artifacts/zaizai-mvp-debug.apk`。

默认后端地址为 `http://127.0.0.1:8787`，适用于 USB 调试转发：

**当前使用 Wi-Fi：** 在 App 登录页展开“服务连接”，将“私有服务地址”改为
`http://172.17.0.174:8787`，然后在“已有账号”中登录，无需重新安装。
此地址不是用户的 CPA 模型代理地址。当前为 HTTP 内测，仅使用测试数据。

**改用 USB：** 先将后端以默认 `.\scripts\start.ps1` 方式启动（监听本机），
并在 App 中把服务地址改回 `http://127.0.0.1:8787`，再执行：

1. 手机开启 USB 调试，连接电脑并在手机上允许调试。
2. 保持本机后端运行。
3. 运行 `.\scripts\install-android.ps1`，安装并建立 `adb reverse` 转发。
4. 在手机上允许麦克风权限；设置提醒时允许通知权限。

断开 USB 后，默认连接不可用。也可以在登录页“服务连接”中填写实际可达的私有后端地址；
局域网监听需明确配置；当前已按上述 Wi-Fi 地址启用。Android WebView 需要较新的系统版本。

本次没有连接安卓真机，APK 编译已验证，硬件收音、外放回声、通知时效和 CSV 文件保存仍需真机验收。

## 开发

Node.js 24，Java 17，Android SDK 34，Gradle 8.2.1。

```sh
pnpm install
pnpm build
pnpm test
pnpm android:sync
```

```powershell
.\scripts\build-android.ps1 -ApiUrl 'http://YOUR_PC_LAN_IP:8787'
```

Wi-Fi 测试包必须指定手机可达的电脑局域网地址。打包脚本会先检查后端，再重新构建并同步网页资源、生成 APK 和校验签名；默认拒绝 `127.0.0.1` 等回环地址。仅在明确使用 `adb reverse` 时加 `-Usb`。脚本使用本机缓存离线构建，首次使用需先准备 Android 构建依赖。

覆盖安装保留手机上手动保存的服务地址；若旧地址错误，请在登录页“服务连接”中改为新的地址。电脑健康检查成功不代表手机与电脑之间的网络已互通。

在当前 Codex 运行环境中，`pnpm` 可通过随 Node 附带的 `pnpm.cjs` 调用。
`.tools/` 为本机安装的构建工具，不随源码分发。

目录：

- `src/`：应用界面、麦克风采集和音频播放。
- `server/`：账号、SQLite、AI 工具调用、记忆、语音中继和主动关心。
- `shared/ledger.mjs`：共用的账目筛选、整数分统计和 CSV 编码。
- `android/`：Capacitor 安卓工程。
- `tests/`：不调用外部 AI 的数据和权限测试。
- `scripts/smoke-*.mjs`：真实接口及浏览器集成检查；AI/语音检查会消耗现有 CPA 额度，纯界面检查不调用模型。
- `artifacts/`：安装包、截图、合成测试音频和验证结果。
- `data/`：本机用户数据库，包含个人信息，不提交版本库。

界面自动化使用 `PLAYWRIGHT_PATH` 指向可用的 Playwright 包，浏览器为 Edge。
图标生成脚本使用 `SHARP_PATH` 指向可用的 Sharp 包。

## 语音验证

CPA `/v1/models` 没列出 Live 不代表没有实时能力。
仓库的 WebRTC 路径默认模型为 `gpt-live-1-codex`；当前实例的直接 WebSocket 实测接受
`gpt-realtime-2.1`，拒绝直接使用 `gpt-live-1-codex`，所以 MVP 使用已测试的前者。
两者均通过用户提供的同一个 CPA，不额外接入其他服务商。

已验证：

- 上游建立真实 session，输出音频和中文文本。
- 显式取消响应返回 `cancelled`，一次测试约 2002ms 收到首段音频，非延迟承诺。
- 合成音频通过 App 后端输入，收到用户转录及模型音频回答。
- 浏览器假麦克风贯穿 AudioWorklet、后端、CPA 和播放链路，触发播放截断和取消事件。

浏览器假麦克风不等于安卓真机麦克风；不能据此保证所有手机的回声消除或插话体验。

## 个人债务往来

- 记账页顶部「债务」标签仅管理个人之间的借出、借入，不包含房贷、信用卡或消费贷。按人汇总、欠条详情、新增和还款均在页内显示；收入录入及关联账目打开的欠条核对仍使用原弹窗。
- 同一账号下按往来人称呼汇总；同名不同人请使用可区分的称呼。每次新增借款始终生成独立账单，不合并、不相互抵销。
- 每笔还款必须选定原借款账单，保留还款日期、金额、备注及按日期计算的剩余欠款。已结清记录仍可查询。
- 债务本金不直接修改；误录账单可填写原因作废。有有效还款时须先核对并撤销还款。撤销、作废都保留历史。
- 「收入 → 债务」只用于收回欠款，先选欠款人和原欠条，再确认还款。入口不开放「我欠别人」的方向。
- 助手文字对话与实时通话共用 `propose_debt_repayment` 工具，只生成 `debt_repayment` 待确认草稿。核对欠款人、原欠条、实际金额和日期后，同一事务更新还款、收入、余额和草稿状态。同人多张欠条须由用户明确选择，不自动分摊。
- 助手不能用普通收入工具代替还款，也不能通过普通确认或批量确认绕过原欠条选择。相同待确认还款草稿复用，确认重试不重复入账。以前误记为普通收入的旧账不自动转换。
- 新登记「别人欠我」的还款，确认后按实际还款日期同步新增一笔收入，界面与导出统一归为「债务」；存储的旧分类「收回借款」不改写、不重复入账。原约定还款日不变，原欠条保留每次还款、日期、备注和剩余余额。原始借款、「我欠别人」的还款及历史还款不自动补记收支。
- 还款与收入在同一事务中保存，重复提交不重复入账。撤销还款时同步撤销对应收入；收入入口打开原欠条，不允许单独改删或恢复关联收入。撤销历史保留在原欠条，不进入普通账目回收站。
- 约定还款日用于记录与逾期标记，本轮不生成通知任务。
- `node --test tests/*.test.mjs` 验证金额、余额、隔离、重复提交及冲突控制；`scripts/smoke-debts.mjs` 在独立临时数据库上验证完整浏览器流程，不修改体验账号数据。
- `scripts/smoke-assistant-repayment.mjs` 验证聊天到还款确认的完整浏览器流程，默认使用测试模型响应；设置 `LIVE_AI_TEST=1` 并通过环境提供已有 CPA 配置可验证真实模型。两种模式均使用独立临时数据库，不写体验账号。

## 助手执行与授权

- 助手可查询本账号账目、待办、体重、回收站、个人欠条、记忆、设置及用量。新增记录仍先生成草稿；修改、移入回收站、恢复、完成待办、个人借还款和设置调整使用待确认操作。
- `prepare_app_action` 只准备操作，后端生成包含对象、金额、日期及关联影响的摘要。模型没有执行或授权工具。点击「确认执行」或在核对后回复「确认」「确认执行」「确认保存」才能执行；「好」「嗯」不视作授权。
- 一次一个待确认操作，5分钟有效。更正、换话题或新的操作会使旧授权失效；核对后数据变化时拒绝执行，要求重新核对。同一操作确认重试不会重复入账。
- 语音等待实际用户转录后处理确认，绑定开口前的操作。核对播报必须完整匹配摘要、播放结束且未被打断，才允许语音确认。未满足时可重新核对或直接检查文字摘要后点击按钮。
- 关联还款复用同一事务；撤销还款同步撤销收入及已消费的助手还款标记。普通删除可从回收站恢复；欠条作废、还款撤销保留原始历史。操作摘要、确认渠道和执行结果保存在本账号 `assistant_actions` 审计表。
- AI 仅调用后端白名单功能，没有任意网络请求、外传、分享、导出、修改模型服务地址或手机控制工具。文本服务拒绝跟随HTTP重定向；必要上下文、语音和用户主动识别的小票仍会传给既有AI服务。
- 清空全部聊天、支付和账号安全操作仍由用户在界面处理；不是给模型任意代码或数据库执行权。手动清空聊天与记忆也会删除助手操作审计记录，正式账目保留。
- `scripts/smoke-assistant-authority.mjs` 使用隔离数据库验证新增、文字确认、修改、按钮确认、还款、重复确认和取消。`LIVE_AI_TEST=1` 使用现有AI配置；额外 `LIVE_VOICE_TEST=1` 验证真实实时模型和合成确认音频，播放结束回执由测试模拟，不代表手机真机测试。

## 注销审核

- `GET /api/account/deletion` 查询本人最新申请；`POST /api/account/deletion` 验证密码与确认信息并提交，每 15 分钟最多尝试 5 次；`POST /api/account/deletion/cancel` 撤回本人待审核申请。
- 手机号、微信、邮箱绑定接口统一返回 `503 BINDING_NOT_CONFIGURED`，未接入外部验证服务。
- 审核仅限本机管理员命令，不开放用户或助手审批接口。先查看待审核申请：

```sh
node scripts/review-account-deletion.mjs --list
```

执行审核前必须停止应用后端，避免活动会话或后台任务继续访问被删除的账号。`--server-stopped` 是管理员的人工确认，不会自动检测或停止服务。核对申请 ID 和用户 ID 后择一执行：

```sh
node scripts/review-account-deletion.mjs --reject REQUEST_ID --confirm-user USER_ID --reason "驳回原因" --server-stopped
node scripts/review-account-deletion.mjs --approve REQUEST_ID --confirm-user USER_ID --server-stopped
```

通过审核会在同一事务内删除当前数据库中该账号及关联记录；失败则回滚，不影响其他账号。历史数据库备份不会自动删除，须管理员另行处理，不能把当前数据库删除视为所有副本均已清除。审核后使用原配置重新启动后端。上述命令不可用于试删真实账号；测试须指定 `--database` 指向独立测试库。

## 设置菜单

- 按功能设置、个性化设置、数据安全、快捷使用、系统设置分组。助手性格、记忆、关系模式、主动关心及暂停关心统一移至“我的 → 我的助手”，不在设置中重复展示。截图中划掉的类别设置、标签设置、图表页设置、去广告不加入菜单；安卓不显示 Siri 入口。
- 可用：账号设置及密码修改；默认记账类型（每次选择/支出/收入）；默认日期范围（整月/今天）；三种主题色；设备支持时的轻触振动；单次待办提醒；全部或指定月份的 CSV 导出；回收站恢复；隐藏顶部汇总；快捷编辑；通知权限查询与申请；应用资源缓存清理。
- 偏好按账号 ID 保存在本机 localStorage，不跨设备同步。隐藏汇总只遮蔽明细、月账单和年账单顶部数值，不是应用锁，不隐藏逐笔账目或导出文件。关闭快捷编辑后先显示账目详情，仍可点击编辑；关联债务始终进入原欠条。
- 资源缓存清理仅处理本应用 `zaizai-` 前缀的 Cache API 缓存，不清除登录凭据、偏好或后台数据，不宣称释放系统 WebView 全部缓存。
- 按键音默认开启，可在“声音与触感”关闭，按账号保存在本机；按钮和应用内虚拟键盘播放低音量短提示音，不改变系统通知或通话音量。通话期间及页面隐藏时暂停，不给手机系统键盘追加音效；声音受设备媒体音量和浏览器音频权限影响。
- 未实现的项目明确显示暂未开放：收支账户、自定义月起始日、数据迁移、周期自动记账、多账本、安卓桌面小组件、模板记账、截屏自动记账、分享邀请。月账单暂按自然月统计。定时提醒仅接现有待办提醒，不代表周期自动记账或助手消息推送。
- 浏览器集成检查 `scripts/smoke-account-services.mjs` 在独立测试库验证设置布局、密码入口、默认收支、日期范围、隐藏汇总、快捷编辑、主题和导出；安卓通知权限和振动仍需真机验证。

## 本机应用锁

- “设置 → 应用锁”可设置独立六位数字密码、至少四点的九宫格手势，可同时保留两种方式。设置需重复输入并验证账号登录密码；关闭、修改和重置也需验证账号密码。
- 开启后，账号内容显示前先检查本机锁配置；重新载入或进入后台后需再次解锁。锁定时卸载受保护的页面和弹窗，正在进行的助手通话会结束。安卓后台事件另由原生插件通知。
- PIN 和手势仅保存随机盐及 PBKDF2-SHA256 哈希（210000 次），不保存原文。安卓配置存于应用私有 SharedPreferences；网页预览存于按账号隔离的 localStorage。连续输错五次冷却60秒，刷新不会重置冷却。配置损坏时禁止显示受保护页面，允许账号密码恢复。
- 人脸入口调用 Android 系统 `BiometricPrompt`，本应用不采集或上传人脸图像。当前实现要求 Android 11+、报告人脸硬件能力且系统允许强生物识别；系统提示可能选择已录入的指纹，不能保证人脸独占。未满足条件时明确不可用，使用密码或手势。先设置备用方式，开启系统验证前需实际验证成功；网页不模拟成功。安卓启用应用锁时设置 `FLAG_SECURE`，阻止常规截屏/最近任务截图。
- 忘记解锁方式时，`POST /api/account/app-lock/verify` 重新校验当前账号、未过期会话及账号密码，每账号15分钟最多5次。通过后仅清除本机应用锁配置，保留账单和聊天；验证失败、断网或登录过期时不重置。该接口不授予新会话或模型权限。
- 边界：这是设备界面防窥锁，不是服务端二次鉴权、数据库加密或抵御开发者工具/Root 的安全隔离。清除浏览器站点数据或卸载 App 会移除本机锁配置；应用恢复需要网络连接私有后端。现有局域网 HTTP 内测连接不提供生产级密码传输保护。
- `scripts/smoke-app-lock.mjs` 使用独立测试库验证设置、错误确认、重载/模拟后台事件、冷却、手势绘制、网页人脸不可用、恢复错误/断网/限次、账号隔离和320/390/430布局。Android 编译不等于人脸、返回前台和设备截屏防护的真机验证。

## 内测边界

- 主动关心只在后端进程运行时生成。App 关闭时尚无 AI 消息推送；安卓已安排的待办通知独立运行。
- 通知受系统权限、节电和调度影响，不承诺闹钟级精确时间。
- 生日为用户自填，尚无正式年龄核验，不能直接据此面向公众开放亲密模式。
- 不提供色情互动、排他性依赖诱导、羞辱或极端减重建议；这些模型提示限制不等于完整安全审核体系。
- 减肥部分目前为体重记录、趋势和可确认待办，不是营养处方或医疗服务。
- SQLite 为单机内测存储，没有多实例协调、数据加密或自动备份。
- 本轮迁移前的手工数据库备份在 `data/backups/`，含个人信息，不应对外分享。CSV 是账目导出，不是完整数据库备份。
- 第一批记账功能已完成。账户、转账退款、预算、周期账单、导入去重及 AI 周报尚未实现。
- 回收站当前保留在后端，不自动清理；断网时尚不能本地离线记账。AI 不可用时，连接正常的手动记录功能不受影响。
- 原始音频不在应用后端落盘；测试合成音频单独保存在 `artifacts/`。
- 对话、转录和记忆会持久化；上游服务可能有自己的日志及数据政策。
- CPA 当前使用 HTTP，已知 HTTPS 握手失败。不要传敏感数据；正式部署须使用可靠的加密连接。
- `POST /api/billing/checkout` 明确返回 `501 BILLING_NOT_ENABLED`，没有模拟支付成功。
- 生产发布前需要更换在聊天中暴露过的密钥、可靠 HTTPS、账号/年龄核验、推送、计费核对和安全验收。
