# 贴边助手（MVP）

## 操作

- 移除右上角的电话和气泡入口，默认显示贴边助手标签，文字和语音共用聊天记录。
- 点击减号收起小窗，露出屏幕边缘的窄标签；可拖到左侧或右侧，也可上下调整。
- 收起、展开、切换功能页不重建通话。绿色标签表示通话仍在进行；在小窗内点挂断结束。
- 安卓首次点击贴边入口申请“显示在其他应用上层”权限；授权且解锁应用后自动启用系统贴边入口。也可在“我的 → 我的助手 → 桌面悬浮助手”中开启或关闭。
- 桌面助手的麦克风权限只在发起语音时请求。未通话时不采集音频。
- 安卓通知栏也提供挂断、关闭助手入口。关闭助手或退出账号会终止通话。
- 网页预览只模拟应用内贴边窗口，无法悬浮在其他应用之上。

## 生命周期和安全边界

- 安卓使用非导出的前台服务，持有独立 WebView；收起只改变窗口尺寸，不重建页面、WebSocket 或音频图。
- 服务明确设置 `stopWithTask=false`。返回桌面、切换应用、从最近任务划掉 App，只收起面板，不停止服务或现有通话。
- 自动启用逻辑位于应用锁内部：未解锁时不启动新助手。已有服务不会因回到 App 而重建或弹出小窗。
- 主动关闭会保存账号对应的关闭标记，返回 App 时不自动重新打开；再次主动点击助手可恢复。该标记不保存登录凭据。
- 复用现有 VoiceCall 和助手操作确认流程，既不读取其他应用内容，也不控制手机。
- 仅加载打包资源，禁止外部导航和 iframe；麦克风授权仅允许本地可信页面，且必须先通过原生语音准备流程。
- 登录凭据通过应用内调用传递，注入本地页面内存，不写入 Intent URL、日志或服务持久化配置。
- 退出账号关闭服务。失效会话检查失败也关闭服务。不会通过后台定时器、开机广播重启，更不会自动续拨；非主动关闭后再次进入已解锁的 App，可以恢复空闲贴边入口。
- 系统锁屏时收起面板；如果启用了应用锁，重新展开前需回到主应用解锁并重新打开助手。通话仍可通过通知主动挂断。
- 系统结束进程、撤销权限、网络断开等故障仍可能中断通话，不能承诺任何机型永不中断。

## 验证

- `node --test tests/*.test.mjs`
- `node scripts/smoke-microphone-status.mjs`：假麦克风和模拟 WebSocket；覆盖贴边拖动、三个手机宽度、收起/切页不重连、同一聊天记录、通话内发文字、静音、权限拒绝及挂断释放麦克风。
- `node scripts/smoke-native-assistant-surface.mjs`：浏览器模拟原生宿主接口；覆盖专用窗口、内存凭据及原生权限握手。不是安卓真机测试。
- `node scripts/smoke-assistant-lifecycle.mjs`：模拟 Capacitor 接口，覆盖首次授权后启用、复用已有服务、主动关闭不重启、重新开启，以及应用锁验证前不启动新助手。不能替代安卓任务移除测试。
- `node scripts/smoke-account-services.mjs`、`node scripts/smoke-bill-period.mjs`：账号、设置、账单回归。
- 安卓 APK 已编译；当前没有连接安卓设备，系统窗口和后台录音尚未完成真机验收。

真机还须验收：首次授权及拒绝、跨应用收起/展开、键盘遮挡、锁屏和应用锁、旋转、通知挂断、退出账号、撤销悬浮权限、断网和系统结束进程。不同系统的前台服务与后台限制可能不同。
